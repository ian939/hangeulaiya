# 아이야 한글놀이 — 사용 안내

EBS 「한글용사 아이야」를 보고, 그 이야기로 받침을 익히는 아이패드 놀이입니다.
현재 **21화 「약」, 22화 「문」, 23화 「돋보기」** 세 편이 준비되어 있습니다.

---

## 1. 켜기 (3단계)

1. 이 폴더의 **`start.bat`** 을 두 번 누릅니다.
2. 검은 창에 주소가 나옵니다. `http://192.168.x.x:8080` 처럼 생긴 주소입니다.
3. 아이패드 Safari 주소창에 그 주소를 입력합니다. PC와 **같은 와이파이**여야 합니다.

끝낼 때는 검은 창을 닫으면 됩니다.

### ⚠️ 처음 한 번은 꼭 해 주세요 — 홈 화면에 추가

아이패드 Safari 는 홈 화면에 추가하지 않으면 **7일 이상 안 쓸 때 저장된 진도를 지웁니다.**

> Safari 아래쪽 **공유 버튼(⬆)** → **홈 화면에 추가**

이렇게 해 두면 아이콘으로 바로 열리고 진도도 지워지지 않습니다.
그래도 가끔 앱의 **부모님 → 내보내기** 로 진도 파일을 저장해 두시면 안전합니다.

## 2. 하루 사용법

**영상 보기와 놀이를 나눠서 하세요.** 한자리에서 30분은 아이에게 무리입니다.

```
① 영상 함께 보기   13~15분   →  ② 5분 이상 쉬기  →  ③ 놀이  6~15분
```

앱에서 회차를 고르면 먼저 영상이 나옵니다. 다 보고 **"다 봤어요!"** 를 누르면
이야기 문제를 풀 수 있게 됩니다.

그다음 두 가지 중에 고릅니다.

| | 활동 | 시간 |
|---|---|---|
| **전체 코스** | 이야기 퀴즈 · 소리 듣기 · 글자 찾기 · 자판기 · 사라진 받침 · 낱말과 그림 · 쓰기 · 이야기 순서 | 12~15분 |
| **짧은 코스** | 이야기 퀴즈 · 소리 듣기 · 자판기 · 쓰기 | 6~8분 |

아이가 지친 날에는 짧은 코스로 같은 회차를 돌려도 됩니다.
핵심 흐름(듣고 → 만들고 → 써 보기)은 짧은 코스에도 다 들어 있습니다.

**새 회차보다 같은 회차를 두세 번 반복하는 게 낫습니다.**

## 3. 부모님이 도와주셔야 하는 부분

| 활동 | 도움 | 무엇을 해 주면 좋은가 |
|---|---|---|
| 이야기 퀴즈 | 낮음 | 한 번 시범 보이고 혼자 하게 |
| 소리 듣고 고르기 | 낮음 | 아이가 답한 뒤 **같이 소리 내어 따라 하기** |
| 글자 찾기 | 낮음 | 혼자 |
| 뭐든지 자판기 | 중간 | "받침은 아래에 들어가" 를 말로 반복 |
| **사라진 받침** | 중간 | **"소리 내서 읽어 봐. 어때, 이상해?"** — 스스로 알아채게 하는 이 말이 핵심입니다 |
| 낱말과 그림 | 낮음 | 혼자 |
| **한글 쓰기** | **높음** | ① 화면 전에 **공중에 손가락으로 크게 써 보기** ② 필요하면 손목을 살짝 받쳐 주기 ③ 잘 그렸는지 평가하지 말고 **방향만** 말해 주기 |
| 이야기 순서 | 중간 | 컷을 보며 함께 이야기해 주기 |

### 회차별로 이 말을 해 주세요

**21화 「약」** — 받침이 있을 때와 없을 때
- "'야' 하고 '약' 을 번갈아 말해 볼까? 끝에서 입이 닫히는 걸 느껴 봐."
- "'국' 을 쓸 때 위의 ㄱ 과 아래 받침 ㄱ, 크기가 다르지?"
- 집에서 받침 ㄱ 찾기: 약, 국, 수박, 축구

**22화 「문」** — 콧소리 받침 ㄴ·ㅁ·ㅇ 구별
- "'문' 은 혀끝이 위에 붙어. '뭄' 은 입술이 붙고, '뭉' 은 목에서 나."
  → 아이 손을 목과 입술에 대 보게 해 주세요.
- "'무' 와 '문' 은 받침 하나로 완전히 다른 낱말이 돼."
- 집에서 받침 ㄴ 찾기: 문, 눈, 손, 산

**23화 「돋보기」** — 소리는 같은데 글자가 달라요 (가장 중요한 회차)
- "'돋' 과 '옷' 과 '낮' 은 끝소리가 똑같이 들려. 그래서 **소리만으로는 못 쓰고 낱말을 기억해야** 해."
- "'돋보기' 세 글자를 같은 크기로 써 보자. 받침 있는 글자가 커지기 쉬워."
- 실제 돋보기로 같이 보면서 "크게 보인다" 를 말로 표현하게 해 주세요.

## 4. 부모님 화면에서 볼 수 있는 것

앱 첫 화면 아래 **👪 부모님** 을 누르면 나옵니다.

- **진도** — 회차별 완료 여부와 별 개수
- **헷갈린 짝** — 아이가 무엇을 무엇으로 잘못 골랐는지 순위. 점수보다 이게 훨씬 쓸모 있습니다.
  예: `ㄴ 를 ㅁ 로 · 3번` → 콧소리 받침을 아직 구별하지 못하는 것
- **아이가 쓴 글자** — 실제로 쓴 글씨 그림
- **진도 보관** — 내보내기 / 불러오기 / 초기화

또래 비교나 점수 등급은 일부러 넣지 않았습니다. 이 나이 문자 발달의 개인차는
정상 범위가 아주 넓어서, 비교 지표는 도움이 되지 않습니다.

## 5. 한글 카드

주신 카드 도안(`아이야 로고 있는_ 기본 한글 카드.png`)을 앱 안에서 그대로 씁니다.

- **모은 카드** — 도안의 빈 글자 틀을 배경으로 쓰고, 가운데에 그 회차에서 배운 자모를 얹습니다.
  회차를 끝내면 카드가 뒤집히듯 나타납니다.
- **아직 못 모은 칸** — 도안의 로고면을 흐리게 보여줍니다. "뒤집혀 있는 카드"로 읽혀서
  빈 회색 칸보다 모으고 싶어집니다. 앨범은 첫 화면 **🗂 한글 카드** 에서 볼 수 있습니다.
- 초성 자리 자모와 받침 자리 자모는 **다른 칸**입니다. 초성 ㄱ 을 아는 것과 받침 ㄱ 을 아는 것은
  다른 지식이고, 방송도 자음 단원(8~20화)과 받침 단원(21화~)을 나눠 가르칩니다.

도안을 바꾸고 싶으면 새 PNG 를 같은 이름으로 두고 `python tools/make_card_art.py` 를 실행하세요.
원본이 A4 인쇄용(7MB)이라 앱에서 쓸 크기로 줄여 넣는 작업입니다.

## 6. 앱이 지키는 규칙

- **"틀렸어요" 라고 하지 않습니다.** 오답이면 그 선택지가 조용히 흐려지고 다시 권합니다.
  X 표시도, 오답 효과음도 없습니다.
- **몇 번 막히면 정답을 보여 줍니다.** 아이가 화면에 갇히는 일이 없습니다.
- **시간 제한이 없습니다.** 언제든 그만둬도 진도는 남습니다.
- **소리는 미리 만들어 넣었습니다.** 기기에 한국어 음성이 없어도 정확한 한국어 발음이 나옵니다.

## 7. 잘 안 될 때

**아이패드에서 주소가 안 열려요**
- PC와 아이패드가 같은 와이파이인지 확인하세요.
- `start.bat` 창이 켜져 있어야 합니다. 닫으면 아이패드에서도 안 열립니다.
- Windows 방화벽이 물어보면 **허용** 을 눌러 주세요.

**"포트 8080 을 열 수 없습니다" 라고 나와요**
- 이미 켜 둔 `start.bat` 창이 있는지 확인하세요. 하나만 켜면 됩니다.
- 다른 프로그램이 8080을 쓰고 있으면 다른 번호로 켜세요.
  검은 창(명령 프롬프트)에서 이 폴더로 이동한 뒤 `start.bat 8081` 처럼 번호를 붙입니다.
  그러면 아이패드에서도 주소 끝을 `:8081` 로 바꿔 접속합니다.

**소리가 안 나요**
- 아이패드 측면의 무음 스위치와 볼륨을 확인하세요.
- 앱은 첫 화면에서 버튼을 한 번 눌러야 소리를 낼 수 있습니다(아이패드 정책). 회차를 고르면 자동으로 준비됩니다.
- 화면 오른쪽 위에 `🔈 소리 없음` 이 보이면 음성 파일을 못 찾은 것입니다. 개발자에게 알려 주세요.

**글씨 쓰기가 너무 어려워요 / 너무 쉬워요**
- 각 회차 데이터의 `toleranceEm`(관용 오차)과 `passScore`(통과 점수)로 조절합니다.
  현재는 21화 0.17 → 23화 0.15 로 조금씩 엄격해집니다. 조정이 필요하면 알려 주세요.

**진도가 사라졌어요**
- 홈 화면에 추가를 안 했을 가능성이 큽니다(위 1번 참고).
- 내보내 둔 파일이 있으면 **부모님 → 불러오기** 로 복구됩니다.

## 8. 다음 회차 늘리기

받침 단원이 이어집니다. 24화 탈(ㄹ) · 25화 잠(ㅁ) · 26화 밥(ㅂ) · 27화 옷(ㅅ) ·
28화 공(ㅇ) · 29화 낮(ㅈ) · 30화 빛(ㅊ).

특히 **27·29·30화는 23화와 한 묶음** 입니다. 옷·낮·빛의 받침이 모두 [ㄷ] 으로 소리나므로,
"소리는 같은데 글자가 다르다" 를 이어서 다루면 효과가 큽니다.

## 9. 저작권

방송 영상은 유튜브 공식 채널(EBS 키즈)을 그대로 불러와 재생합니다. 복제하지 않습니다.
놀이 화면의 장면 그림은 방송 화면 캡처가 아니라 이야기 내용을 보고 새로 그린 그림입니다.
이 폴더는 우리 집 학습용입니다. 외부에 올리거나 배포하지 마세요.
