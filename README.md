# 아이야 한글놀이

EBS 「한글용사 아이야」를 본 뒤, 그 이야기로 **받침**을 익히는 태블릿 학습 놀이입니다.
아이패드 Safari와 안드로이드 Chrome에서 바로 열립니다. 설치도, 로그인도 없습니다.

**▶ 바로 해보기 — https://ian939.github.io/hangeulaiya/**

> 읽기는 되는데 **쓰기가 약한 6~7세**를 위해 만들었습니다.
> 받침이 시작되는 21화부터가 그 아이들의 실제 병목입니다.

---

## 지금 들어있는 회차

| 회차 | 낱말 | 학습 초점 |
|---|---|---|
| 21화 | 약 | 받침 ㄱ — **받침이 있을 때와 없을 때** (야 / 약) |
| 22화 | 문 | 받침 ㄴ — **콧소리 받침 구별** (문 / 뭄 / 뭉) |
| 23화 | 돋보기 | 받침 ㄷ — **소리는 같은데 글자가 달라요** (돋 / 옷 / 낮) |

세 편의 초점을 일부러 다르게 잡아 받침의 세 가지 난관을 훑습니다.
23화가 가장 값이 큽니다. 받침 ㄷ·ㅅ·ㅈ·ㅊ·ㅌ은 **모두 [ㄷ]으로 소리나서**,
소리만 듣고는 쓸 수 없고 낱말을 기억해야 합니다. 쓰기가 약한 아이의 병목이 정확히 여기입니다.

## 활동 8종

영상을 먼저 보고(유튜브 임베드), 그다음 놀이를 합니다.

1. **이야기 퀴즈** — 그 회차에서 무슨 일이 있었는지
2. **소리 듣고 고르기** — 받침 유무, 콧소리 구별, 소리·표기 불일치
3. **글자 찾기** — 목표 자모를 격자에서 모두 찾기
4. **뭐든지 자판기** — 자모 타일을 초성·중성·종성 칸에 넣어 낱말 만들기
5. **사라진 받침** — 망가진 낱말에서 틀린 곳을 찾아 고치기
6. **낱말과 그림** — 만든 낱말을 뜻과 연결
7. **한글 쓰기** — 획순 안내를 따라 손가락으로 쓰고 채점받기
8. **이야기 순서** — 장면을 이야기 순서대로 놓기

지친 날에는 **짧은 코스**(4활동, 6~8분)로 같은 회차를 돌릴 수 있습니다.
핵심 루프(듣고 → 만들고 → 써 보기)는 짧은 코스에도 다 들어 있습니다.

## 설계에서 신경 쓴 것

- **"틀렸어요"라고 하지 않습니다.** 오답이면 그 선택지가 조용히 흐려지고 다시 권합니다.
  X 표시도, 오답 효과음도 없습니다. 몇 번 막히면 정답을 보여줘 화면에 갇히지 않게 합니다.
- **환호는 소리로 내지 않습니다.** 소리는 발음 시범과 학습 설명에만 씁니다.
  칭찬을 음성으로 읽히면 아이가 기다리는 시간만 늘어납니다.
- **설명이 끝날 때까지 기다립니다.** 고정 시간으로 다음 문제로 넘기면 긴 설명이 잘립니다.
- **낱자는 글꼴이 아니라 획 데이터로 그립니다.** ㅗ는 위, ㅜ는 아래로 잉크가 몰려 있어서
  글자로 찍으면 칸마다 높이가 들쭉날쭉해집니다. 따라쓰기 안내선과 같은 도형을 씁니다.
- **또래 비교·점수 등급이 없습니다.** 이 나이 문자 발달의 개인차는 정상 범위가 아주 넓습니다.
  대신 부모 화면에 **"헷갈린 짝"**(무엇을 무엇으로 잘못 골랐는지)을 보여줍니다.

## 기술

프레임워크·번들러·의존성이 없습니다. `index.html`을 열면 그게 전부입니다.

- 순수 HTML/CSS/JS, 클래식 `<script>` 태그, 전역 네임스페이스 `AIYA` 하나
- **회차 추가 = 파일 하나 + `index.html`에 한 줄.** 빌드도 재시작도 없습니다
- 한글 조립은 유니코드 공식으로 계산 (`0xAC00 + (초성×21 + 중성)×28 + 종성`)
- 쓰기 채점은 캔버스 픽셀 대신 폴리라인 기하로. 커버리지 × 정밀도, 방향·시작점 검사
- 자모 40개 × 획 1~4개 = **폴리라인 약 90개**를 저작하면 음절 블록 배치로 11,172자가 전부 나옵니다
- 음성은 미리 만든 MP3. 런타임 TTS를 쓰지 않는 이유는 안드로이드 Chrome이 한국어 음성팩 없이도
  `ko-KR`이 있다고 보고하고 영어 음성으로 읽어버리기 때문입니다

### 로컬에서 돌리기

```bash
python tools/serve.py        # http://localhost:8080
```

Windows에서는 `start.bat`을 두 번 누르면 됩니다. 같은 와이파이의 태블릿에서 접속할 주소도 알려줍니다.

### 검사

```bash
node tools/lint_content.mjs   # 회차 데이터 · 누적 자모 규칙 · 에셋 · 음성 커버리지
```

브라우저에서 `#/selftest` — 한글 11,172자 분해→조립 왕복, 획 데이터, 채점, 회차 스키마 (115항목)

### 개발용 도구

| 도구 | 하는 일 |
|---|---|
| `tools/serve.py` | 로컬 서버. 태블릿 접속 주소를 찾아 보여준다 |
| `tools/fetch_transcript.py` | 회차 한국어 자동 자막 받기 (줄거리 파악용) |
| `tools/make_tts.py` | 발화 문구를 모아 MP3 생성 (`edge-tts` 또는 Windows SAPI) |
| `tools/make_card_art.py` | 한글 카드 도안을 웹용 크기로 변환 (도안은 저장소에 없음) |
| `tools/lint_content.mjs` | 콘텐츠 검사기 |

## 저작물에 대해

- **영상**은 유튜브 공식 채널(EBS 키즈)을 임베드로 재생합니다. 복제하지 않습니다.
- **장면 그림**은 방송 화면 캡처가 아니라, 자막으로 줄거리를 파악한 뒤 새로 그린 SVG입니다.
- **한글 카드 도안**은 방송 로고가 들어간 저작물이라 이 저장소에 포함하지 않았습니다.
  없으면 CSS의 대체 배경이 쓰이고, 기능은 그대로 동작합니다.
- 「한글용사 아이야」와 EBS의 상표·저작권은 각 권리자에게 있습니다.
  이 저장소는 그 방송을 보고 만든 **비공식 학습 도구**이며 EBS와 관련이 없습니다.
